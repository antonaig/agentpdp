# AgentPDP

Paste a product page URL. Get an agent-ready version of it: a clean product page that registers **WebMCP site tools** bound to the real product data, plus a **merchant control plane** that logs every agent call and lets the merchant switch each tool on, off, or behind a human confirm.

Built for the [OpenAI WebMCP Challenge](https://openai.com/webmcp-challenge/) (Aug 25 – Sep 4, 2026) by [Aigency](https://aigency.ai). MIT.
